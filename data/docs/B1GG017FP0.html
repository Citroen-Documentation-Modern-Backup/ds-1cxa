B1GG017FP0Dépose - repose : Radiateur de refroidissement moteur
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Placer le véhicule sur un pont élévateur à 2 colonnes.
Débrancher la batterie .
Déposer :
  • La protection sous moteur
  • Le pare-chocs avant
Vidanger le circuit de refroidissement.
Figure : b1gg00xd
Déclipper le faisceau électrique  (en "a").
Déconnecter les connecteurs  (en "b", "c", "d").
Figure : b1gg0a5d
Déposer le conduit d’air (1).
Figure : b1gg09kd
Désaccoupler :
  • La durit (3)
  • La durit de dégazage du radiateur de refroidissement
Déposer :
  • Les vis (2), (4)
  • Les 2 vis du support moteur avant droit (Côté longeron)
Pousser le moteur vers l’arrière.
Figure : b1gg09ld
Déposer le motoventilateur (5) (par le dessous du véhicule).
ATTENTION : Ne pas détériorer les ailettes du radiateur de refroidissement.
Figure : b1gg0acd
Déposer les vis (6).
Figure : b1gg0add
ATTENTION : Ne pas détériorer les ailettes du radiateur de refroidissement.
Écarter le radiateur de refroidissement moteur (Suivant la flèche ).
Déposer :
  • Les brides de maintien (8)
  • Le radiateur de refroidissement moteur (7) (par le dessous du véhicule)
2. Repose
ATTENTION : Respecter les couples de serrage .
NOTA : Vérifier la présence des bagues caoutchouc inférieures sur la cassette de refroidissement.
Remettre en place le radiateur de refroidissement (7) .
Reposer :
  • Les brides de maintien (8)
  • Les vis (6)
  • Le motoventilateur (5)
Figure : b1gg09nd
Réintroduire les pattes de fixation du motoventilateur (5) dans leurs logements (en "f ", "g").
Reposer :
  • Les vis (2), (4)
  • Les 2 vis du support moteur avant droit
Accoupler :
  • La durit de dégazage du radiateur de refroidissement
  • La durit (3)
Reposer le conduit d’air (1).
Connecter les connecteurs  (en "d", "c", "d").
Reclipper : Le faisceau d’alimentation du motoventilateur (en "a").
Remplir et purger le circuit de refroidissement.
Contrôler l’étanchéité du circuit de refroidissement.
Reposer :
  • Le pare-chocs avant
  • La protection sous moteur
