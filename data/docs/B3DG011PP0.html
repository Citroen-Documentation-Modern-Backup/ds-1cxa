B3DG011PP0Dépose - repose : Fusée arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Desserrer le frein de stationnement .
Lever et caler le véhicule.
Déposer :
  • La roue arrière
  • Le capteur de roue arrière (Partiellement - Côté roue)
1.1. Véhicule équipé de frein arrière à tambour
Déposer :
  • Le tambour de frein arrière
  • Les segments de frein arrière
Figure : b3fg0nxd
Desserrer l’écrou (1).
Désaccoupler et écarter le raccord (2).
Dégager le câble de frein de stationnement du plateau ( en "a").
Déposer :
  • Les vis (3)
  • L’ensemble plateau/fusée /cylindre de roue
Figure : b3fg0nyd
Déposer :
  • Les vis (4)
  • La fusée
1.2. Véhicules équipés de freins à disques à l’arrière
Déposer le moyeu disque de frein arrière .
Figure : b3dg0l5d
Déposer :
  • Les vis (6)
  • La fusée (5)
2. Repose
ATTENTION : Respecter les couples de serrage.
Couples de serrage :
  • Train arrière
  • Système de freinage
  • Roue
2.1. Véhicule équipé de frein arrière à tambour
Reposer :
  • La fusée sur le plateau
  • Les vis (4)
  • L’ensemble plateau/fusée /cylindre de roue
  • Les vis (3)
  • Engager le câble de frein de stationnement dans la plateau de frein  (en "a")
Accoupler le raccord (2) ; Serrer l’écrou (1).
Reposer :
  • Les segments de frein arrière
  • Le tambour de frein arrière
Purger le circuit de freinage .
2.2. Véhicules équipés de freins à disques à l’arrière
Reposer :
  • La fusée (5)
  • Les vis (6)
  • Le moyeu disque de frein arrière
3. Repose (Suite)
Reposer :
  • Le capteur de roue arrière
  • La roue arrière
Reposer le véhicule sur ses roues.
