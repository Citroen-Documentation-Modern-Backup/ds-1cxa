2. Dépose
IMPERATIF : Respecter les consignes de sécurité et de propreté spécifiques aux motorisations haute pression diesel injection (HDI) .
2.1. Opérations préliminaires
Figure : b1bg0t7d
Déposer :
  • La protection sous moteur
  • Le collier d’échappement
Vidanger le circuit de refroidissement.
Déposer : Les 2 vis du support moteur avant droit (Côté longeron).
Tirer le moteur vers l’avant.
Déposer :
  • Le cache-style moteur (1)
  • Le cache-style batterie (3)
  • Les conduits d’air (4)
Débrancher la batterie .
Déposer :
  • Le système d’admission d’air intégré supérieur  (2)
  • Le système d’admission d’air intégré inférieur
Figure : b1hg154d
Déconnecter les connecteurs des injecteurs diesel (en "a").
Écarter la barrette porte faisceau électrique (5).
Déposer :
  • L’atténuateur de bruit turbocompresseur (7)
  • Le déshuileur (6) (*)
NOTA : (*) Mettre en lieu et place l’outil [0194-T1].
Figure : b1hg157d
ATTENTION : Nettoyer les raccords haute pression avant desserrage .
Déposer : Le tube de recyclage des gaz d’échappement (8).
Écarter : Le tuyau de retour carburant (9) ; Obturer à l’aide de l’outil [0194/2-E].
Desserrer les raccords (10) sur les injecteurs diesel ; Appliquer un contre-couple pour desserrer les raccords (en "b").
Figure : b1hg15cd
Déposer le support (11).
Écarter le faisceau d’alimentation des bougies de préchauffage (12).
Figure : b1hg15dd
Desserrer les raccords (14).
Déposer les 4 tubes d’alimentation haute pression carburant (13).
ATTENTION : Obturer les raccords sur les injecteurs diesel et sur la rampe d’injection commune haute pression carburant, à l’aide des bouchons [0194/2-E].
2.2. Extraction d’un injecteur diesel (si nécessaire)
Figure : b1hg15ed
ATTENTION : Repérer l’emplacement de chaque injecteur diesel par rapport aux cylindres.
Déposer les 8 écrous (15).
Mettre en place l’outil [1616-A].
Poser l’outil d’extraction [1616-A] sur l’injecteur diesel (16).
Figure : b1hg15fd
ATTENTION : Ne pas intervenir sur l’écrou en "c".
Déposer (injecteur par injecteur) :
  • L’injecteur diesel (16) ; À l’aide de l’outil [1616-A]
  • La bride (21)
  • Les fourreaux porte-injecteurs diesel (17)
  • La bague d’étanchéité (20)
  • Le joint cuivre d’étanchéité (18)
ATTENTION : Obturer le puits de l’injecteur diesel, le nez de l’injecteur diesel ; À l’aide de l’outil [0194/2-E].
Déposer :
  • L’outil [1616-A]
  • Les vis colonnettes (19)
NOTA : Les vis colonnettes (19) sont remplacées au remontage.
2.3. Extraction d’un joint cuivre (si nécessaire)
Figure : b1hg15gd
Desserrer l’outil [0194/2-C] de quelques tours.
Poser l’outil [0194/2-C] sur le joint cuivre (18) dans le puits d’injecteur diesel .
Serrer à fond la vis de l’outil [0194/2-C] pour bloquer le joint cuivre (18).
ATTENTION : Obturer les puits d’injecteurs diesel ; À l’aide de l’outil [0194/2-E].
Déposer le joint cuivre (18) en manoeuvrant l’outil [0194/2-C].
2.4. Nettoyage des puits d’injecteurs diesel
Figure : b1hg15kd
ATTENTION : Ne pas nettoyer les puits d’injecteurs diesel si la culasse est neuve.
Poser l’outil [0194/2-D] dans le puits d’injecteur diesel .
ATTENTION : Ne pas forcer en manoeuvrant l’outil [0194/2-D], risque de détériorer le puits d’injecteur diesel.
Nettoyer le puits d’injecteur diesel en tournant l’outil [0194/2-D] dans le sens horaire.
Déposer l’outil [0194/2-D].
Aspirer les puits d’injecteurs diesel ; À l’aide de l’aspirateur et de l’embout rond.
ATTENTION : Obturer les puits d’injecteurs diesel ; À l’aide de l’outil [0194/2-E].
3. Repose
ATTENTION : Respecter les couples de serrage .
ATTENTION : Remplacer les joints d’étanchéité par des joints neufs.
3.1. Injecteurs diesel réutilisés
ATTENTION : Reposer les injecteurs diesel dans les cylindres en respectant leurs emplacements par rapport aux cylindres notés lors du démontage.
3.2. Injecteurs diesel neufs
ATTENTION : Relever le numéro de classification des injecteurs diesel (8 caractères) Noter le ou les cylindres recevant un injecteur diesel neuf.
3.3. Opérations communes
Figure : b1hg15fd
ATTENTION : Remplacer systématiquement les joints cuivre (18).
ATTENTION : Remplacer systématiquement les vis colonnettes (19).

  • Préserrage au couple
  • Serrage au couple

  • Clipper la bride (21) sur l’injecteur diesel (16)
  • Monter à plat le joint cuivre neuf (18) dans le puits d’injecteur diesel
  • Poser la bague d’étanchéité neuve (20) dans le puits d’injecteur diesel
  • Poser le fourreau (17) dans le puits d’injecteur diesel
  • Poser l’injecteur diesel (16) muni de sa bride (21)

ATTENTION : Arrêter le serrage manuel lorsque le jonc d’arrêt vient au contact du carter chapeaux de palier.
Préserrer les écrous (15) au couple ; À l’aide des outils [1608-A] et [1608-D].
Figure : b1hg15rd

  • Placer l’index mobile "e" en face de l’angle de serrage préconisé
  • Serrer progressivement, et en une seule fois, en ramenant l’index mobile "e" en face du zéro (repère "d" de l’outil [1608-C])
ATTENTION : Lors de la repose, tous les joints d’étanchéité déposés doivent être remplacés par des joints d’étanchéité neufs.

Actionner simultanément le démarreur et la pompe d’amorçage manuelle jusqu’au démarrage du moteur.
ATTENTION : Entrer le numéro de classification des injecteurs diesel neufs à l’aide de l’outil de diagnostic.
Laisser tourner le moteur au ralenti pendant 2 minutes.
4. Contrôle d’étanchéité
Mettre le véhicule sur un pont élévateur.
Pulvériser le produit détecteur de fuites sur les raccords injecteurs diesel et sur la rampe d’injection commune haute pression carburant .
Démarrer le moteur.
Vérifier l’absence de fuite.
Accélérer jusqu’à un régime de 4000 tr/mn.
Vérifier l’absence de fuite.
Faire un essai routier.
Vérifier l’absence de fuite.
Remplacer les pièces défectueuses.
Reposer :
  • La protection sous moteur
  • Le cache-style moteur (1)
