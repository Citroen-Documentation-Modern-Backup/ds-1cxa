B1GG0171P0Dépose - repose : Motoventilateur
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Débrancher la batterie .
Déposer la protection sous moteur .
Vidanger le circuit de refroidissement.
Figure : b1gg00xd
Déclipper le faisceau électrique  (en "a").
Déconnecter les connecteurs  (en "b", "c", "d").
Figure : b1gg09jd
Déposer le conduit d’air (1).
Poser un pince-durit  (en "e").
Figure : b1gg09kd
Désaccoupler la durit (3).
Déposer :
  • Les vis (2), (4)
  • Les 2 vis du support moteur avant droit (Côté longeron)
Pousser le moteur vers l’arrière.
Figure : b1gg09ld
Déposer le motoventilateur (5) (par le dessous du véhicule).
ATTENTION : Ne pas détériorer les ailettes du radiateur de refroidissement.
Figure : b1gg09md
Déposer le boîtier (6) (Motoventilateur (5)).
2. Repose
Reposer :
  • Le boîtier (6) sur le motoventilateur
  • Le motoventilateur (5)
Figure : b1gg09nd
Réintroduire les pattes de fixation du motoventilateur (5) dans leurs logements (en "f ", "g").
Reposer :
  • Les vis (2), (4)
  • Les 2 vis du support moteur avant droit
Accoupler la durit (3).
Déposer : Le pince-durit.
Reposer le conduit d’air (1).
Connecter les connecteurs  (en "b", "c", "d").
Reclipper : Le faisceau d’alimentation du motoventilateur (en "a").
Rebrancher la batterie.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Remplir et purger le circuit de refroidissement.
Démarrer le moteur ; Attendre l’enclenchement puis le déclenchement du motoventilateur.
