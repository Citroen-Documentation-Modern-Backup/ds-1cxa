"A" : Côté admission.
"B" : Côté boîte de vitesses .
"C" : Côté échappement .
1. Contrôle
Vérifier le jeu aux soupapes :
  • Admission : minimum : 0,15 mm   maximum : 0,20 mm
  • Échappement : minimum : 0,35 mm   maximum : 0,40 mm
2. Réglage
ATTENTION : Respecter les couples de serrage .
Régler le jeu aux soupapes :
  • Admission : minimum : 0,15 mm   maximum : 0,20 mm
  • Échappement : minimum : 0,35 mm   maximum : 0,40 mm
Mettre à pleine ouverture la soupape d’échappement Régler la soupape d’admission Régler la soupape d’échappement

3c 4a 2c
4c 2a 1c

Serrage des contre-écrous  (suivant équipement) :
  • Diamètre M9 = 1,75 m.daN
  • Diamètre M6 = 0,9 m.daN
Remplacer :
  • Le joint du couvre-culasse
  • Les rondelles d’étanchéité sous les écrous
Reposer :
  • La tôle déflectrice
  • Les deux entretoises
  • Le couvre-culasse et son joint
  • La rampe de bobine d’allumage ( 3)
  • Les vis ( 2)
Replacer :
  • Le faisceau électrique
  • Le tube (1)
Accoupler le tube ( en "b" ).
Replacer : L’électrovanne canister (4) sur son support.
